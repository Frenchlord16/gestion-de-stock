# Gestion Stock - PC Windows

## Lancement
Double-clique sur `Lancer_Gestion_Stock.bat`.

Cette version utilise Python et Tkinter, sans bibliothèque supplémentaire.

Fonctions :
- Tableau de bord
- Gestion des marchandises
- Ajout / modification / suppression
- Entrées et sorties de stock
- Historique des mouvements
- Fournisseurs
- Prix d'achat et de vente
- Valeur du stock
- Alertes de stock faible
- Recherche

Les données sont enregistrées automatiquement dans `stock_data.json`, dans le même dossier que l'application.

Si Windows indique que Python n'est pas installé, installer Python 3 depuis le site officiel python.org puis relancer le fichier BAT.
